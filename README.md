<h2>✨ Sobre o projeto</h2>

<p align="center">
Este projeto demonstra, de forma visual e prática, como diferentes estratégias de busca impactam o desempenho em sistemas de banco de dados.
</p>

<ul>
  <li>🔵 <b>Hash Index:</b> acesso direto via função hash</li>
  <li>🟣 <b>Table Scan:</b> varredura sequencial das páginas</li>
</ul>

<hr>

<h2>⚙️ Funcionalidades</h2>

<ul>
  <li>📂 Upload de arquivo <code>.txt</code></li>
  <li>📄 Paginação dos dados</li>
  <li>🧮 Construção de índice hash</li>
  <li>⚠️ Controle de colisões e overflow</li>
  <li>🔍 Busca por palavra</li>
  <li>📊 Comparação de desempenho (tempo e custo)</li>
  <li>👁️ Visualização das páginas com destaque</li>
</ul>

<hr>

<h2>📊 Métricas</h2>

<p align="center">
⏱️ Tempo • 📄 Páginas acessadas • 💥 Colisões • 📦 Overflow
</p>

<h2>🎯 Resultado</h2>

<ul>
  <li>⚡ O <b>Hash Index</b> é mais rápido e eficiente</li>
  <li>🐢 O <b>Table Scan</b> tem maior custo</li>
</ul>
